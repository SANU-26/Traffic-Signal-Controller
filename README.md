# Traffic-Signal-Controller
FPGA based Traffic signal controller using verilog HDL and Vivado.
Overview
An FPGA-based traffic signal control system designed using Verilog HDL. The project implements sequential traffic signal operations using Finite State Machine (FSM) logic.

Features
- FSM-based traffic signal control.
- Automated signal sequencing.
- RTL design using Verilog HDL.
- Testbench-based functional verification.
- FPGA synthesis and implementation.

Technology Stack
- HDL: Verilog
- Design & Simulation: Xilinx Vivado
- Platform: FPGA

Project Structure
- "Source_Code/" – Verilog design files
- "Testbench/" – Verification files
- "Constraints/" – FPGA constraint files
- "Simulation_Results/" – Simulation waveforms
- "Implementation_Results/" – Synthesis and implementation screenshots

Design Flow
RTL Design → Functional Simulation → Synthesis → Implementation → Bitstream Generation→ Hardware implementation

Results
The design was functionally verified through RTL simulation. Synthesis and implementation results are included in the repository.
